# Modern SaaS FAQ Pro

افزونه وردپرسی **Modern SaaS FAQ Pro** یک سیستم مدرن مدیریت پرسش‌های متداول (FAQ) است که با تمرکز بر UI/UX مدرن و یکپارچگی با **Elementor** و **Gutenberg** طراحی شده است. این افزونه امکان ساخت «مجموعه‌های FAQ» را به‌صورت **CPT** (Custom Post Type) فراهم می‌کند و با شورت‌کد، بلوک گوتنبرگ و ویجت المنتور در فرانت‌اند نمایش می‌دهد.

---

## امکانات کلیدی

- 📌 **پست‌تایپ اختصاصی FAQ**
  - نوع نوشته: `msaas_faq_set`
  - نام در پیشخوان: «⚡ FAQ مدرن»
  - مناسب برای ساخت مجموعه‌های مختلف پرسش و پاسخ (برای صفحات، محصولات، لندینگ‌ها و …)

- 🧩 **شورت‌کدهای انعطاف‌پذیر**
  - شورت‌کد اصلی:
```php
[saas_faq id="25"]
